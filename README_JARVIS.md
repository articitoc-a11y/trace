# 🤖 J.A.R.V.I.S. — голосовой помощник с игровым меню

Голосовой помощник, который по команде **«Джарвис, открой меню»** открывает
красивое неоновое меню (стиль Железного человека) с ярлыками игр. Ярлыки можно
добавлять как прямо из меню кнопкой «＋ Добавить игру», так и голосом.

## Файлы
| Файл | Назначение |
|---|---|
| `jarvis.py` | сам помощник: распознавание речи + TTS + локальный сервер меню |
| `jarvis_menu.html` | интерфейс меню (можно открыть и двойным кликом, без Python) |
| `games.json` | база ярлыков игр (создаётся автоматически) |

## Установка
```bash
pip install -r Requirements.txt
```
Нужны: `speech_recognition` (+ микрофон), `pyttsx3` (голос), опционально `keyboard`.
На Windows всё ставится из коробки; на Linux для pyaudio нужен `portaudio19-dev`,
для pyttsx3 — `espeak-ng`.

## Запуск
```bash
python jarvis.py            # голосовой режим
python jarvis.py --text     # текстовый режим (если нет микрофона)
```

## Голосовые команды
| Команда | Действие |
|---|---|
| **«Джарвис, открой меню»** | открывает игровое меню в браузере |
| «Джарвис, закрой меню» | закрывает меню |
| «Джарвис, добавь игру *Ведьмак* путь *D:\Games\…\game.exe*» | добавляет ярлык |
| «Джарвис, запусти *Ведьмак*» | запускает игру по названию |
| «Джарвис, выход» / «пока» | выключает помощника |

Горячая клавиша **Ctrl+Alt+M** — открыть меню без голоса (нужен пакет `keyboard`).

## Возможности меню
- 🔍 живой поиск по играм;
- ➕ добавление ярлыков прямо в окне («＋ Добавить игру»: название, путь к .exe/.lnk, URL обложки);
- ✕ удаление ярлыка (крестик при наведении);
- ▶ клик по карточке = запуск игры через `/api/launch`;
- 💾 сохранение в `localStorage` + синхронизация с `games.json` через локальный API;
- ⏰ часы, анимированный «реактор», неоновые карточки — тёмный стиль J.A.R.V.I.S.

## Как это работает
1. `jarvis.py` слушает микрофон и распознаёт речь Google (`ru-RU`).
2. По команде «открой меню» поднимается лёгкий HTTP-сервер на `127.0.0.1:8765`
   и в браузере открывается `jarvis_menu.html`.
3. Меню общается с сервером через API: `GET /api/games`, `POST /api/games`,
   `POST /api/launch` — поэтому добавленные в меню игры видны и голосовым
   командам («запусти …»), и наоборот.
